# How to run (reviewer):
#   1. Seed BOTH databases identically (dotnet ef database update + seeders on
#      the .NET side; the Python side reads the same schema).
#   2. Start both APIs, then from api-python/:
#      python tools/parity.py --routes tools/parity_routes.txt \
#        --ignore timestamp,traceId,traceid,appliedMigrationsCount,occurredAt,createdAt,updatedAt,postedAt,awardedAt,submittedAt,approvedAt,lastRunAt,lastLoginAt
#      (Timestamps differ between the two calls; extend --ignore as needed.)
#   3. Run ONCE per fresh seed: write routes (signup, post, award, ...) mutate
#      both databases, so a second run compares different states.
#   4. Cookie/JWT routes (/api/auth/me, /api/me/*, /api/admin/*, chat, exercise
#      workspace/draft, lesson/problem progress, v2 progress) 401 on both sides
#      here because parity.py sends only x-api-key; that still compares the
#      401 shape. IDs/slugs below come from the stock seed data; adjust them
#      if your local seed differs.
#

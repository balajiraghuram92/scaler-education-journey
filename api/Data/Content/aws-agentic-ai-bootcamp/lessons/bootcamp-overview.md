# Bootcamp Overview

Agentic AI on AWS · Scaler

#### Scaler *AWS AI* Bootcamp

Learn to build AI agents on AWS: start with one Strands agent on Amazon Bedrock and end with a team of agents running in production, then use them on real finance problems. Each week has its recordings, lessons and solution code.

- **Agents on Bedrock** What an agent is, the Strands agent loop, and your first agent on Amazon Bedrock.
- **Tools and memory** Turn Python functions into tools, and give agents short-term and long-term memory.
- **Agents together** Multi-agent patterns, and MCP and A2A for talking to tools and other agents.
- **Production** Ship agents on Lambda, ECS or Bedrock AgentCore, then build finance projects with them.

Handling Reserved Keywords
Identifying Reserved Keywords
Issue: SQL keywords such as "user", "show", and "row" conflict with MySQL and PostgreSQL reserved words.
Solution: Utilize @Entity(name = "new_table_name") in Hibernate to rename the tables to "users" and "shows" for compatibility.

The Booking Flow And The Race Condition
Booking Process
Selection: Users select seats, but no reservation is yet made.
Confirmation: Sets a temporary hold on selected seats.
Payment: Finalizes the booking within a set period (e.g., 15 minutes).
Race Condition
Occurs when two or more users attempt to book the same seat concurrently. The naive check-then-act sequence fails, leading to possible double-booking.
Solving The Race Condition
Soft Locking Approach
Soft Lock: Use the ShowSeatStatus field to indicate if a seat is BLOCKED (held temporarily).
Database Handling: Applied the SERIALIZABLE isolation level in database transactions to ensure one-at-a-time execution order for conflicting operations.
